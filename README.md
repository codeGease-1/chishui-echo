## 在 GitHub Pages 发布

1. 创建公开仓库，例如 `chishui-echo`。
2. 将本目录**内部的文件和 assets 文件夹**上传到仓库根目录。
3. 打开 Settings → Pages。
4. Source 选择 **Deploy from a branch**；Branch 选择 **main**，目录选择 **/(root)**，点击 Save。
5. 部署完成后，访问 `https://你的用户名.github.io/chishui-echo/`。

这是可直接部署的静态网站，无需 npm、Vite 或额外构建。
保留 assets 目录结构。视频已压缩为网页版本，无需上传原始大视频。
每次刷新返回首页并清空本轮答题、模拟和盖章记录；同一页面内切换栏目保留进度。

GitHub 官方说明：https://docs.github.com/zh/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
